# luz-prices

Static JSON cache of day-ahead prices (DE-LU, AT, NL) for the Luz por Horas app. Fetched by GitHub Actions (6x/day, respecting the 2 req/min limit of api.energy-charts.info) and served by GitHub Pages. Data: Bundesnetzagentur | SMARD.de via Energy-Charts.info (Fraunhofer ISE), CC BY 4.0. See site/index.html.
